# AL HUSSAM Travel - Applied Design System

> Curated from UI UX Pro Max (Trust & Authority + Soft UI Evolution + Hotel/Hospitality trust colors), adapted for Islamic pilgrimage faith & trust.

## Pattern
**Trust & Authority + Conversion**
- Hero (mission / credibility) → Proof stats → Faith statement → Packages → Solution → Testimonials → Affiliations → CTA

## Style
**Soft UI Evolution** - soft multi-layer shadows, calm depth, 200–300ms motion, high contrast, spacious density.

## Colors (applied)
| Role | Hex | Notes |
|------|-----|-------|
| Primary / Emerald | `#0F3D2E` | Faith, peace, authority |
| Soft Emerald | `#1B5C43` | Secondary surfaces |
| Mist | `#E7F0EB` | Soft UI chip / icon bg |
| Ivory background | `#F6F3EC` | Calm paper-like light |
| Ivory deep | `#EFEBE3` | Alt sections |
| Gold CTA | `#B8956C` | Sacred accent (CTA only) |
| Gold deep | `#9A7A4F` | Hover / emphasis |
| Ink | `#15231F` | Body text |
| Muted | `#5A6B64` | Secondary text |

## Typography
- **Headings:** Lora (calm, spiritual, readable)
- **Body:** Raleway
- **RTL:** Noto Nastaliq Urdu

## Effects
- Soft shadows `0 8px 28px rgba(15,61,46,0.08)`
- Hover lift 2–6px, 220ms
- Visible `:focus-visible` rings
- `prefers-reduced-motion` respected

## Avoid
- Neon / purple-pink AI gradients
- Harsh animations / dark-mode-first UI
- Emoji-as-icons
- Complex booking friction without guidance
